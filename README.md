# Naitik Sahu's Portfolio

> hii , I made this website for fun . Not my main portfolio , but its cool .

**Live at:** [https://naitiklearn.github.io/naitik-portfolio/](https://naitiklearn.github.io/naitik-portfolio/)

---

## 🚀 What's Inside

| Section | Description |
|---|---|
| **Hero** | Full-screen red grid with floating draggable stickers, bold NAITIK title |
| **About** | Scroll-pinned rotating panels — unfiltered chapters about who I am |
| **I Love Movies** | Animated horizontal movie poster strip |
| **Some Designs** | GSAP & Canvas 2D cylindrical 3D gallery showcasing posters with zero cropping (Hank-D-Tank cylinder gallery) |
| **What I Can Do** | Skills & interests grid — Code, ML, Design, Growing |
| **Scrapbook** | Community & visitor guestbook displaying doodles, names, and notes in a 3-column grid |
| **Wanna Be Friends?** | Contact form + live drawing canvas with direct Scrapbook integration |

---

## 🛠 Tech Stack

- **HTML5** — semantic, no frameworks
- **CSS** — custom design system with tokens, dark/light sections
- **JavaScript** — GSAP, GSAP Observer, ScrollTrigger, Lenis smooth scroll, Draggable, Canvas 2D
- **Fonts** — Black Han Sans, Montserrat, Inter, Syne, Space Mono

## 📁 Project Structure

```
naitik-port/
├── index.html                  ← Main page
├── css/                        ← Modular stylesheets
│   ├── tokens.css              ← Design tokens (colors, spacing, fonts)
│   ├── reset.css               ← CSS reset
│   ├── nav.css
│   ├── hero.css
│   ├── about.css
│   ├── work.css                ← Movies section
│   ├── designs.css             ← 3D Cylinder gallery styles
│   ├── skills.css
│   ├── scrapbook.css           ← Scrapbook guestbook grid & modal styles
│   ├── contact.css
│   └── marquee.css
├── js/                         ← Section-specific scripts
│   ├── main.js                 ← Lenis + GSAP init, nav logic
│   ├── hero.js
│   ├── about.js                ← Scroll panel animation
│   ├── work.js                 ← Movie poster strip
│   ├── designs.js              ← Hank-D-Tank 3D cylinder slice gallery
│   ├── scrapbook.js            ← Scrapbook cards, drawing modal, & local storage
│   └── contact.js              ← Canvas drawing tool + form
└── components/                 ← Assets by section
    ├── hero-sec/               ← Hero cutout stickers + background
    ├── moviesposter-animation/ ← Movie poster images
    └── posters/                ← Design poster collection
```

## ✨ Features

- Smooth scroll via **Lenis**
- Scroll-pinned panel animations via **GSAP ScrollTrigger**
- Interactive 3D poster flip showcase
- Draggable floating stickers
- Live HTML5 canvas drawing in the contact section
- Fully responsive
